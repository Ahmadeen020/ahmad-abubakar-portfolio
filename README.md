# Ahmad Abubakar — Portfolio

React + Vite portfolio configured for GitHub Pages.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

In GitHub, open **Settings → Pages** and select **GitHub Actions** for Build and deployment. The included workflow deploys on pushes to `main`.

## Before publishing

- Replace `your-email@example.com` in `src/App.jsx` with the email address you want displayed.
- Replace the LinkedIn URL with your actual profile.
- Review project descriptions and links for accuracy.
- Add the selected profile photo at `public/images/profile.jpg`.
